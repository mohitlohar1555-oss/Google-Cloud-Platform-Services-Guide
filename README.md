## 📌 About This Project

Welcome to my **Google Cloud Platform (GCP) Services Guide** repository.

This repository contains detailed documentation about Google Cloud Platform services, including their features, working principles, advantages, use cases, best practices, pricing models, and quick-start commands.

The guide is designed for beginners, students, cloud enthusiasts, and IT professionals who want to understand Google Cloud services.

## 📚 Topics Covered

### 1. 💻 Compute Services
- Compute Engine
- Google Kubernetes Engine (GKE)
- Cloud Run
- App Engine
- Cloud Run Functions
- Batch

### 2. 💾 Storage Services
- Cloud Storage
- Persistent Disk and Hyperdisk
- Filestore

### 3. 🗄️ Database Services
- Cloud SQL
- AlloyDB for PostgreSQL
- Cloud Spanner
- Firestore
- Cloud Bigtable
- Memorystore

### 4. 🌐 Networking Services
- Virtual Private Cloud (VPC)
- Cloud Load Balancing
- Cloud CDN
- Cloud DNS
- Cloud NAT
- Cloud VPN and Cloud Interconnect

### 5. 📊 Data Analytics Services
- BigQuery
- Pub/Sub
- Dataflow
- Dataproc
- Cloud Composer
- Dataplex and Data Catalog
- Looker and Looker Studio

### 6. 🤖 AI & Machine Learning
- Vertex AI
- Pre-trained AI APIs
- Gemini for Google Cloud and Gemini Enterprise
- TPUs and GPUs

### 7. 🔐 Security & Identity
- Identity and Access Management (IAM)
- Cloud KMS and Secret Manager
- Security Command Center
- VPC Service Controls, Cloud Armor and IAP

### 8. ⚙️ DevOps & Operations
- Cloud Build and Artifact Registry
- Cloud Deploy
- Cloud Monitoring, Logging and Trace
- Infrastructure as Code (IaC)
